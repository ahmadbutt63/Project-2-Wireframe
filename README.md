# Project-2-Wireframe
Here's what I learned building VogueStore's homepage skeleton:

✅ Information Hierarchy comes before aesthetics — always
✅ Friction is the invisible enemy of every conversion
✅ Whitespace is not empty space — it's an active design tool
✅ Strategic CTA placement can make or break a user journey
✅ The 5-Second Test: if a user can't find what you sell in 5 seconds, you've already lost them

From the hero section to the trust signals, every element was placed with intention — not decoration.

Structure first. Color later. 🧱
